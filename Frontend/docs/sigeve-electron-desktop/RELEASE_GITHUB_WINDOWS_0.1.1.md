Entrega atualizada do `GeoLimites Desktop` para Windows, alinhada ao estado mais recente do sistema.

### Inclui

- instalador `NSIS`
- executavel portatil
- pacote `.zip` portatil

### Arquivos

- `GeoLimites-Desktop-Setup-0.1.1-x64.exe`
- `GeoLimites-Desktop-Portable-0.1.1-x64.exe`
- `GeoLimites-Desktop-0.1.1-win-x64-portable.zip`

Para distribuicao principal ao usuario final, priorizar o arquivo `Setup`.
