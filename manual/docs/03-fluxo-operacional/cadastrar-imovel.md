# Cadastrar Imovel

## Onde essa tela aparece no menu

No menu lateral atual, **Cadastrar Imovel** fica em **Preparacao**.

Essa tela e usada quando o usuario precisa criar um novo imovel ou concluir o cadastro tecnico de um imovel que ainda nao esta pronto.

## Objetivo

O cadastro do imovel organiza a base juridica e operacional do trabalho.

Ele pode reunir:

- identificacao do imovel
- dados basicos
- proprietarios
- documentos
- arquivos vinculados
- referencias tecnicas relevantes para o processamento

## Como o fluxo funciona

O cadastro e feito de forma assistida, normalmente em etapas.

No fluxo mais recente, o usuario pode passar por abas como:

- dados basicos
- proprietarios
- documentos
- arquivos
- resumo final

## O que revisar antes de salvar

Antes de concluir o cadastro, vale conferir:

1. se a identificacao do imovel esta correta
2. se os proprietarios estao completos
3. se os documentos principais foram vinculados
4. se os arquivos tecnicos correspondem ao imovel certo
5. se o resumo final nao ficou com pendencias

## Relacao com o restante do sistema

O cadastro do imovel melhora a operacao porque ajuda a alimentar:

- a identificacao usada no memorial
- o contexto juridico do trabalho
- a organizacao dos arquivos vinculados ao imovel

Depois do cadastro, o fluxo costuma seguir para:

- **Imoveis**, para selecao do item correto
- **Editor CAD**, para validacao do desenho
- **Configurar Memorial**, para preparar a etapa documental

## Boa pratica

Nao use o cadastro apenas como formalidade.

Quanto melhor o imovel estiver cadastrado:

- mais claro fica o contexto do trabalho
- menor o risco de inconsistencias documentais
- mais facil fica revisar o memorial final
